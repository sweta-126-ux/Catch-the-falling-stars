🎮 A fun and beginner-friendly browser game where you catch falling stars and score points!

---

## 🌐 Live Demo
👉 https://sweta-126-ux.github.io/catch-the-stars/

---

## 📌 About The Project
Catch The Falling Stars is a simple 2D browser-based game built using HTML, CSS, and JavaScript.  
The objective is to move the player left and right to catch falling stars and increase your score.

---

## 🎮 Gameplay
- Move the player using arrow keys  
- Catch falling stars ⭐  
- Earn points for each catch  
- Try to beat your high score!  

---

## 🕹️ Controls
- ⬅️ Left Arrow → Move Left  
- ➡️ Right Arrow → Move Right  

---
